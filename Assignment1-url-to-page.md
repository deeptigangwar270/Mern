# What Happens Between Typing a URL and Seeing a Webpage?

When we type a URL in the browser and press Enter, several steps happen before the webpage appears.

### Steps:

1. **URL:** We enter a website address in the browser.
2. **DNS Lookup:** DNS converts the domain name into an IP address.
3. **Server Connection:** The browser connects to the web server.
4. **HTTP Request:** The browser sends a request to the server.
5. **Server Response:** The server sends HTML, CSS, and JavaScript files.
6. **Rendering:** The browser processes these files and displays the webpage.

### Conclusion:
The browser uses DNS, HTTP, HTML, CSS, and JavaScript to load and display a webpage.
